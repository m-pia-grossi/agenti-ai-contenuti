# Content Image

> **Origine metodologica:** Mastella repo/webinar: testo e immagini sono output diversi e vanno gestiti con skill separate.

## Input
- post o idea approvata
- canale
- `references/graphics.md` della skill chiamante

## Output
- obiettivo del visual
- cosa deve mostrare
- testo esatto da inserire, se necessario
- formato/aspect ratio
- eventuali elementi da evitare
