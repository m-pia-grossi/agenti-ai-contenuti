# Integrazione Content Manager

Questa repository parte dal fork del materiale `agenti-ai-contenuti` di Luca Mastella e aggiunge un livello operativo personale per Codex/ChatGPT.

## Cosa è stato preservato
- Tutte le cartelle originali Mastella: `.claude/`, `procedure/`, `toolkit/`, `esempio/`.
- `README.md` originale invariato.
- `AGENTS.md` originale salvato come `AGENTS-MASTELLA-ORIGINALE.md`.

## Cosa è stato aggiunto
- `AGENTS.md` — istruzioni operative del Content Manager.
- `agents/content-linkedin.md` — specializzazione LinkedIn.
- `skills/content-linkedin/` — skill e reference LinkedIn.
- `skills/revisione-anti-ai/` — revisione stilistica.
- `skills/content-image/` — skill immagini.
- `archivio/`, `dati/`, `bozze/`, `routines/` — dati e flusso operativo.
- `MAPPA-PERSONALIZZAZIONE.md` — cosa mantenere e cosa personalizzare.
- `README-CONTENT-MANAGER.md` — guida del livello aggiunto.

## Nota importante
I file in `archivio/` e alcune reference sono placeholder da sostituire con dati, voce e performance personali prima di usare la routine automatica.
